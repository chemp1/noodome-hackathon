# Вайб-кодинг-хакатон Noodome · 5 сентября · 3 часа

Материалы трёхчасового хакатона команды Noodome: 6 треков с пресетами —
у каждого бриф на 120 минут (цель = один живой пользовательский путь),
синтетические данные и готовый стартовый промпт. Скоуп изобретён до хакатона,
команды тратят время только на билдинг.

## Программа: 3 часа

| Время | Что происходит |
|-------|----------------|
| за 1–2 дня | Сетап 1:1 по 15 минут: входы работают, стартовые промпты открыты, каркас бота задеплоен; опрос-бейзлайн разослан |
| 0:00–0:20 | Вводная 8′+6′+6′: контекст и кейсы · живой пример вайб-кодинга (не из наших треков!) · правила |
| 0:20 | Старт по стартовым промптам. Первые 20 минут растерянности — норма |
| 1:20 | Обход-чекпоинт: помощники с тремя вопросами самопроверки из брифов |
| 2:00 | Заморозка скоупа: только полировка одного пути |
| 2:10 | Бэкап-запись экрана (2 минуты на команду) |
| 2:20–2:45 | Демо 6×4′: 2′ живой путь (показывает автор боли) + 1′ промпт и что проверили руками + 1′ вопрос судей |
| 2:45–3:00 | Номинации · у каждого прототипа — владелец и дата пилота · ссылки в общий чат |

## Три правила участника (на каждом столе)

1. **Начни с разведки:** «покажи, что в этих файлах».
2. **Проси конкретный результат:** «сделай экран с тремя карточками и поиском», а не «сделай красиво».
3. **Проверяй след данных:** возьми строку из исходника и найди её в результате.

Застрял — спасательный промпт: «Задай мне вопросы, чтобы лучше понять, каким должен быть этот продукт».

⚠️ **Правило данных:** весь хакатон работаем только на синтетике из этих папок.
Реальные данные участников клуба и переписки в облачные ИИ не загружаем.
В синтетике намеренно спрятаны ошибки — как в жизни; кто найдёт, говорит на демо.

## Судейство

Пять критериев по 0–3 балла (максимум 15), публикуются до начала:

| Критерий | Вопрос судьи |
|----------|--------------|
| Работает вживую | Один реальный путь показан в действии, не на скриншотах |
| Боль снята | Автор боли подтверждает: «это решает мою проблему» |
| Путь к внедрению | Понятно, что нужно, чтобы пользоваться через 30 дней |
| Честность ИИ | Показан промпт; проверяли руками; поймали ли выдумку или ошибку в данных |
| Понятность демо | Коллега из любого отдела понял без пояснений |

Плюс номинации вне рейтинга: «Скорее всего будут пользоваться» ·
«Больше всех экономит времени» · «Лучшая провокация ИИ» · «Народный прототип»
(голосование, приз — выходной) · «Открытие дня».

## После хакатона (48 часов)

- Ссылки на все прототипы — в общий чат в тот же вечер.
- У каждого прототипа — владелец (автор боли) и дата первого использования в работе (≤ 30 дней).
- Лучшие промпты и сессии — в библиотеку промптов Noodome (стартер-кит следующей итерации).
- Через неделю — повтор опроса «пользуешься ли ИИ ежедневно?».
- Следующая итерация — через квартал; цель-мечта — вайб-кодинг-вечер для участников клуба в амфитеатре.
