# Вне трёхчасового формата · Таск-трекер для коллектива

**Автор идеи:** Егор (Программинг)

В трёхчасовой формат этот трек не вошёл: задача хорошая учебная, но generic
(тысячи готовых решений), а автор идеи нужнее хакатону в роли помощника —
одна из двух подписок на ИИ во всей команде.

Материалы оставлены для самостоятельной сборки после хакатона:

- [seed-tasks.json](seed-tasks.json) — 8 стартовых задач, статусы, команда.

## Стартовый промпт

> Сделай канбан-доску для небольшой команды (5 человек) на русском языке.
> Колонки: Бэклог, В работе, На проверке, Готово. Карточка задачи: название,
> ответственный (выбор из списка команды), дедлайн, теги отдела, комментарии.
> Нужно: перетаскивание карточек между колонками, создание и редактирование
> задач, фильтр по ответственному, красная подсветка просроченных дедлайнов.
> Данные сохраняются в localStorage. Стартовые задачи загрузи из JSON, который
> я приложу. Дизайн чистый, светлый, рабочий.

Вторая идея из той же заявки — навигатор партнёрских интеграций — собирается
на этой же доске: карточка = партнёрский пакет, колонки = стадии реализации.
