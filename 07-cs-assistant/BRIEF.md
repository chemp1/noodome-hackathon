# Трек F · AI-ассистент клиентского сервиса

**Автор боли:** Олеся (Клиентский сервис) · **Формат:** 120 минут практики

## Важная рамка

Большая идея (единый контакт-центр с Битрикс, MAX, почтой) — проект на месяцы.
Задача хакатона — прототип умного ядра, который станет аргументом в защиту
большого проекта.

## Цель — один живой путь

Оператор вставляет входящее обращение → мгновенно получает категорию, риск
недовольства и готовый черновик ответа в тоне клуба → правит и отправляет.

## Как собираем (без кода)

Рабочее место — проект в Claude с настроенным системным промптом:

1. Создать проект «Ассистент КС Noodome», в инструкции проекта вложить: категории обращений, шаблоны ответов из [dialogues.md](dialogues.md), правила тона.
2. Прогнать все 12 синтетических обращений, сверить с эталонной разметкой (в конце dialogues.md — не подглядывать до проверки!).
3. Тюнить инструкцию, пока классификация не совпадёт минимум в 10 из 12.
4. Бонус: попросить Claude собрать интерфейс-артефакт «лента обращений со светофором риска» на этих 12 диалогах.

⚠️ Реальные переписки с участниками в облако не загружаем — только синтетика.

## Стартовая инструкция проекта

> Ты — ассистент клиентского сервиса частного клуба Noodome. На каждое входящее
> обращение отвечай строго в формате: КАТЕГОРИЯ (гости / бронирования / жалоба /
> биллинг / членство / онбординг / благодарность / прочее) · ТОНАЛЬНОСТЬ ·
> РИСК (🟢/🟡/🔴 с пояснением) · ЧЕРНОВИК ОТВЕТА — тёплый, профессиональный,
> по подходящему шаблону, обращение по имени, без канцелярита. Если в обращении
> две боли — разбери обе. Повторное обращение = риск выше.

## План 120 минут

- **0:00–0:20** — создать проект, вложить инструкцию и шаблоны, прогнать 3 обращения.
- **0:20–1:40** — прогнать все 12, сверить с эталоном, тюнить инструкцию; черновики довести до «не стыдно отправить».
- **1:40–2:00** — проверка по 3 вопросам, свежее обращение из головы, бэкап-запись экрана.

## Три вопроса самопроверки (в 1:20)

1. Классификация сходится с эталоном минимум в 10 из 12?
2. Обращение №12 помечено красным? №5 — учтено, что оно повторное?
3. Черновик ответа на №2 (сбой брони) содержит извинение и срок — отправила бы такой?

## Готово, если

- [ ] Живой путь показан за 2 минуты: вставить новое обращение → категория + риск + черновик.
- [ ] Точность на эталоне названа вслух (X из 12).
- [ ] С понедельника этим реально можно пользоваться в работе.
- [ ] Бэкап-запись экрана сделана до демо.
