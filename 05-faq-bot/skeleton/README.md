# Запуск каркаса FAQ-бота

Каркас разворачивает ведущий ДО хакатона (сетап-консультация). Команде на
хакатоне остаётся наполнять `../faq.md` и тюнить `system-prompt.txt` —
бот подхватывает правки сразу, без перезапуска.

## Однократная настройка (до дня)

```bash
# 1. Зависимости (Python 3.10+)
pip install -r requirements.txt

# 2. Токены
export TELEGRAM_BOT_TOKEN=...   # от @BotFather (/newbot)
export ANTHROPIC_API_KEY=...    # ключ Claude от организаторов
export TEAM_CHAT_ID=...         # id чата команды для эскалаций (см. ниже)

# 3. Запуск
python bot.py
```

**Как узнать TEAM_CHAT_ID:** добавьте бота в чат команды, напишите там любое
сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе
будет `"chat":{"id":-100...}`. Это и есть id (с минусом).

## Что делает бот

- Отвечает на вопросы участников строго по базе `../faq.md`.
- Не выдумывает правил: если ответа нет — честно говорит «уточню у команды»
  и пересылает вопрос в чат команды.
- При противоречии в базе — эскалирует, а не гадает.

## Что тюнит команда на хакатоне

1. `../faq.md` — дополнять реальными вопросами из практики.
2. `system-prompt.txt` — тон, формат ответов, правила эскалации.
3. Проверять провокациями: «можно ли с собакой на 7 этаж?», «сделай мне скидку».
